# P2 트레이너 (비계 다이얼 Lv1~3) Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 큐레이션 카드 48장을 소비하는 비계 다이얼(Lv1 조립 → Lv2 부분 인출 → Lv3 백지)을 RN 앱에 세우고, Lv3 실패 지점을 어휘 카드로 승급시켜 풀 수 있게 한다. 3탭 셸까지 세워 P1이 캡처 화면만 꽂으면 되게 한다.

**Architecture:** 순수 엔진(`services/trainer/*`) → 저장소·스토어 seam → 다이얼 컴포넌트 → 셸. 엔진은 store를 모르고, 화면은 store만 본다. 레벨은 저장하지 않고 `masteryLabel` 밴드에서 파생한다.

**Tech Stack:** TypeScript(strict) · Jest(jest-expo) · **@testing-library/react-native(신규)** · Zustand · React Navigation(bottom-tabs, 설치됨)

**스펙:** `docs/superpowers/specs/2026-08-01-p2-trainer-design.md`
